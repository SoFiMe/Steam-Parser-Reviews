# 📊 Steam Reviews Parser
Парсер для сбора и анализа отзывов из Steam Store. Программа имеет графический интерфейс и сохраняет данные в Excel с автоматической статистикой по языкам.

## 🚀 Возможности
- 📥 Сбор отзывов по **AppID** игры
- 🔗 Поддержка вставки **полной ссылки** на игру (авто-извлечение AppID)
- 🌍 Определение **языка** каждого отзыва
- 📅 Сохранение **даты создания** отзыва
- 📊 Автоматическая **статистика по языкам** на втором листе Excel
- 🎯 Прогресс-бар и статус загрузки
- 📋 Поддержка контекстного меню для вставки

## 🛠 Быстрый старт

1. **Установите зависимости:**
```bash
pip install aiohttp pandas openpyxl
```
2. **Запустите программу:**
```bash
python steam_parser.py
```
3. Введите AppID или ссылку на игру в Steam.
4. Нажмите "Проверить" — программа покажет общее количество отзывов.
5. Введите количество отзывов для выгрузки.
6. Нажмите "Начать загрузку" и дождитесь завершения.
7. Результат — файл {AppID}_reviews.xlsx в папке с программой.

## 🎮 Что такое AppID и где его найти?
**AppID** — это уникальный числовой идентификатор игры в Steam. Каждая игра имеет свой номер.

**Как найти AppID:**
1. Откройте страницу игры в Steam (например, в браузере или в клиенте Steam).
2. Посмотрите на адресную строку браузера: `https://store.steampowered.com/app/730/Counter-Strike_2/`
3. Число после `/app/` — это и есть AppID. В примере выше это **730**.

**Что можно вводить в поле:**
- Только число: `730`
- Полную ссылку: `https://store.steampowered.com/app/730/Counter-Strike_2/`
- Часть ссылки: `store.steampowered.com/app/730`

## 📁 Структура выходного файла
Файл сохраняется как `{AppID}_reviews.xlsx` и содержит **два листа**:

### 📄 Лист 1: `Отзывы`

| Столбец | Описание |
|---------|----------|
| **Ссылка на отзыв** | Прямая гиперссылка на отзыв в Steam Community. По клику откроется страница автора с этим отзывом. |
| **Отзыв** | Полный текст отзыва, который оставил пользователь. Может содержать форматирование (жирный, курсив, списки, спойлеры и т.д.). |
| **Тип отзыва** | `Положительный` — пользователь рекомендует игру. `Отрицательный` — пользователь не рекомендует игру. |
| **Язык** | Код языка, на котором написан отзыв. Примеры: `english`, `russian`, `schinese`, `brazilian`, `french` и т.д. |
| **Дата создания** | Дата и время, когда был написан отзыв. Формат: `ГГГГ-ММ-ДД ЧЧ:ММ:СС`. Примеры: `2024-01-15 14:23:45`. |
| **Helpful** | Количество людей, которые отметили этот отзыв как **"Полезный"**. |
| **Funny** | Количество людей, которые отметили этот отзыв как **"Смешной"**. |
| **Кол-во игр** | Общее количество игр в библиотеке автора отзыва. Показывает, насколько опытным может быть игрок. |
| **Кол-во отзывов** | Сколько всего отзывов написал этот пользователь в Steam. |
| **Часов наиграно** | Сколько часов автор провел в этой игре на момент написания отзыва. Округлено до 2 знаков после запятой. |

### 📊 Лист 2: `Статистика по языкам`
Сводная аналитика по языкам отзывов:

| Столбец | Описание |
|---------|----------|
| **Язык** | Код языка (например, `english`, `russian`, `schinese`). |
| **Кол-во отзывов** | Сколько всего отзывов написано на этом языке. |
| **Положительные** | Количество положительных отзывов на этом языке. |
| **Отрицательные** | Количество отрицательных отзывов на этом языке. |
| **% от общего числа** | Какой процент от всех собранных отзывов написан на этом языке. |
| **% положительных от языка** | Процент положительных отзывов среди отзывов на этом языке. |
| **% отрицательных от языка** | Процент отрицательных отзывов среди отзывов на этом языке. |

## 📌 Как интерпретировать столбцы

### `Helpful` и `Funny`
Эти метрики показывают **реакцию сообщества** на отзыв:
- `Helpful` → отзыв полезен для принятия решения о покупке.
- `Funny` → отзыв забавный, его часто читают ради юмора.

**Пример:**
| Отзыв | Helpful | Funny |
|-------|---------|-------|
| Серьезный обзор с анализом геймплея | 1500 | 20 |
| Шутка про русских в команде | 300 | 2900 |

### `Кол-во игр` и `Кол-во отзывов`
Эти столбцы помогают оценить **авторитетность автора**:
- Если у автора **много игр** и **много отзывов** — вероятно, он опытный игрок, к мнению которого стоит прислушаться.
- Если у автора **мало игр** и **это первый отзыв** — возможно, он новичок или эмоциональный покупатель.

### `Часов наиграно`
Показывает, сколько времени автор провел в игре. Это важно, потому что:
- **0–5 часов** — возможно, пользователь только начал играть.
- **50+ часов** — пользователь хорошо знаком с игрой.
- **500+ часов** — опытный игрок, который знает все нюансы.

### `Дата создания`
Помогает отслеживать:
- **Свежие отзывы** — что говорят о игре сейчас.
- **Старые отзывы** — как менялось мнение со временем (особенно после обновлений).

### `Язык`
Показывает, на каком языке написан отзыв. Это полезно для:
- Анализа регионального восприятия игры.
- Поиска отзывов на конкретном языке.
- Понимания, какие языковые сообщества наиболее активны.
